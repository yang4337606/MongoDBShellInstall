三步完成安装

1

上传软件包

将脚本、MongoDB 三个离线包及可选的 mongdb-offline-rpm.tar.gz 上传至服务器 /soft 目录

2

配置参数

使用在线命令生成器选择安装模式（单机/副本集）并配置安装参数

3

执行命令

复制生成的命令，以 root 用户在服务器上执行即可

核心特性

为什么选择 MongoDBShellInstall

面向运维场景的可复核 MongoDB 自动化安装方案

⚡

版本感知配置

根据 MongoDB 版本自动适配配置：6.1+ 移除 journal.enabled，5.0+ 移除 enableMajorityReadConcern，8.0+ 启用 TCMalloc THP

🔧

WiredTiger 智能调优

根据有效内存自动计算 cacheSizeGB，配置 journalCompressor=snappy，blockCompressor=snappy，directoryForIndexes

📦

OS 深度优化

tcp_keepalive_time、vm.swappiness=1、readahead、NUMA、THP 版本感知；安装时关闭防火墙与 SELinux

🎯

完整离线安装

MongoDB 三包自动识别；ISO 缺失依赖使用 mongdb-offline-rpm.tar.gz，并按 OS 主版本与 CPU 架构隔离

🛡

副本集自动化

DNS 成员、并行远程部署、相同二进制指纹跳过传输；支持 keyFile、可选 TLS/X.509 与管理员认证

📄

备份与监控脚本

检测到 Database Tools 时启用 mongodump 定时备份，并生成可返回故障状态的健康检查脚本

部署模式

两种模式，灵活适配

根据业务场景选择最合适的部署模式

⚙

单机模式

Standalone

单节点 MongoDB 部署，适用于开发测试和中小型数据存储场景。默认无认证并监听 0.0.0.0

快速部署 开发测试 中小数据
🔰

副本集模式

Replica Set

多节点副本集集群，自动选举 PRIMARY 节点。推荐 3+ 节点（奇数），认证和 keyFile 可选

高可用 自动故障转移 生产推荐
